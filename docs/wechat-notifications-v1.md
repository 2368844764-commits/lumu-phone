# 微信主动消息与通知规则 V1.2

本模块属于游戏内模拟微信，并非真实微信接口。无需剧情即可测试通知。

## 前端测试
1. 打开微信 → 我 → 设置 → 新消息通知。
2. 选择“发送一条测试通知”或“5 秒后模拟主动来消息”。
3. 发送延时通知后返回桌面；等待游戏内横幅，点击可打开对应聊天。
4. 可分别关闭横幅、声音、震动、消息正文预览。
5. 在聊天信息中可设置置顶、免打扰；会话列表可标记未读。
6. 本地消息/通知设置存储于当前浏览器，不与其他设备自动同步。

## 管理后台发布数据
已有发布配置字段 `appManager.wechat` 可添加：

```json
{
  "scheduledMessages": [
    {
      "id": "intro-message-001",
      "personId": "contact-id-from-contacts",
      "content": "这里填管理员审核过的消息内容",
      "trigger": "delay",
      "delayMs": 15000,
      "enabled": true,
      "once": true,
      "notify": true
    }
  ],
  "replyRules": [
    {
      "personId": "contact-id-from-contacts",
      "trigger": "你好",
      "reply": "这里填符合人物设定的回复",
      "delayMs": 900,
      "enabled": true
    }
  ]
}
```

自动消息可用 `trigger: "at"` 加 `at: "2026-11-16T12:00:00+08:00"` 设置绝对时间；默认按本次浏览器会话首次启动时间加 `delayMs` 执行。消息 ID 防重复（当前浏览器只触发一次）。如需每位玩家独立的剧情计时，应后续增加服务端玩家身份、进度及消息调度。

人物回复目前是“关键词/兜底规则”，不是 AI 人设模型。AI 生成应由后端安全代理提供接口，禁止把模型密钥放在前端源码中。

## 环境限制
仅网页打开期间调度事件；不支持页面关闭后的系统推送。首次交互之前浏览器可能禁止声音，部分 iPhone Safari 不支持网页震动。通知音是模拟提示音，不是从微信提取的受版权保护音频。
